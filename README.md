# ⚡ VoltShare — Global EV Charging Network Simulation Engine

[![Language](https://img.shields.io/badge/Language-PL%2FSQL-blue.svg)](#)

VoltShare is an enterprise-grade relational database architecture engineered to simulate, monitor, and manage a high-frequency global Electric Vehicle (EV) charging infrastructure. Developed as a core project for the **Data Management 2** module at the **NIBM School of Computing & Engineering**.

The system coordinates real-time data flows between geographical charging hubs, multi-tier user configurations, system operators, and complex financial transaction processing layers.

---

## 🏗️ Architectural Blueprint & Schema Design

The relational schema is fully normalized ($3\text{NF}$) and comprised of **10 interconnected database tables** designed to maintain strict data integrity, eliminate redundancy, and minimize transaction latency.
